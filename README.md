# s-arc

**S-ARC (Southern Architecture)** is a curated architectural commerce & collaboration platform bridging discerning homeowners with verified South Indian architects through transparent pricing and complete, construction-ready blueprint packages.

## Features
- **Curated Architectural Marketplace**: Detailed 42-sheet architectural drawing sets, structural drawings, and MEP schedules.
- **Smart Plot Search**: Filter by plot dimensions, orientation (Vastu/facing), and topography.
- **Architect Directory**: Verified Council of Architecture (COA) credentials and studio portfolios.
- **Inside Out Viewer**: 3D axonometric and floor plan schedule exploration.
- **Multi-Role Authentication**: Dedicated onboarding for Homeowners, Licensed Architects, and Turnkey Contractors.

## Getting Started

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
